# Phase 9 — Classic Designs: Timed Cold Circuit

README §19. Every design already had a **learning pass** in the phase that taught its concepts.
This phase is the **second pass**: interview conditions, cold.

**Rules for every session here**
- `/design <system> full`: 45 min timed (60 for advanced), no warm-up, no notes, no hints.
- Voice-dictated answers; diagram in Excalidraw/paper, image saved to `journal/assets/`.
- The interviewer picks the deep-dive and adds ≥ 1 curveball (new requirement, 10× scale, region loss).
- Pass mark: **≥ 95/120** (advanced: **≥ 90**). Below that → remediation (re-teach the weakest 2
  rubric categories) → re-attempt later in the circuit, in a *different order*.
- Order within each cycle is shuffled by the mentor. Don't prepare for a specific one.
